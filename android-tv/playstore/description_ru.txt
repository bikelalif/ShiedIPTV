=== SHORT DESCRIPTION ===
Премиум IPTV-плеер для ваших плейлистов M3U и кодов Xtream.

=== FULL DESCRIPTION ===
Плеер ShieldIPTV — это ультрасовременный медиаплеер, разработанный для обеспечения максимального удобства при просмотре и быстром переключении каналов на любых экранах. Наслаждайтесь современным, плавным и премиальным интерфейсом, специально оптимизированным для удобной навигации с помощью пульта дистанционного управления (телевизоры и приставки на Android TV).

ВАЖНО: ShieldIPTV не предоставляет, не продает и не сдает в аренду какой-либо медиаконтент. Приложение представляет собой пустой медиаплеер. Вы должны импортировать собственные легальные плейлисты (ссылки M3U, ключи Xtream API), предоставленные вашим дистрибьютором.

КЛЮЧЕВЫЕ ОСОБЕННОСТИ:
• Универсальная поддержка: легко подключайтесь через Xtream Codes API или импортируйте ссылки на плейлисты M3U/M3U8.
• Ультрабыстрое переключение: оптимизированный движок воспроизведения для мгновенной загрузки каналов без задержек.
• Телепрограмма (EPG): полная интеграция ТВ-гида, позволяющая сразу увидеть, что идет в эфире сейчас или планируется позже.
• Мини-плеер (Картинка в картинке): просматривайте прямой эфир в небольшом окне во время просмотра списка остальных каналов.
• Обход блокировок провайдеров: дополнительная интеграция безопасного протокола DNS over HTTPS (DoH) для обхода сетевых ограничений на потоковую передачу, налагаемых некоторыми операторами связи.
• Раздел Фильмы и Сериалы (VOD): специальный раздел для просмотра ваших фильмов и сериалов по запросу с сортировкой по сезонам и сериям.
• Внешний плеер: полная совместимость и перенаправление в ExoPlayer для максимальной поддержки нативных аудио- и видеокодеков вашего устройства.
• Эргономика Android TV: на 100% адаптировано для навигации с помощью D-pad и стандартных пультов дистанционного управления.

ОТКАЗ ОТ ОТВЕТСТВЕННОСТИ:
- ShieldIPTV Player не предоставляет и не включает в себя медиаданные или контент.
- Пользователи должны предоставлять свой собственный контент через действующие плейлисты.
- ShieldIPTV не имеет никакого отношения к сторонним поставщикам потокового вещания.
- Мы не одобряем потоковую передачу материалов, защищенных авторским правом, без разрешения правообладателя.
